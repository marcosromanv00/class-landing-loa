# Library of America: Rediseño Visual

Estudio avanzado de jerarquía visual y tipografía moderna aplicado al rediseño de la interfaz de Library of America.

## 🚀 Overview
Este proyecto se centra en la optimización de la experiencia de lectura digital, aplicando principios de diseño editorial al entorno web. El objetivo principal fue mejorar la legibilidad y la navegación a través de una estructura clara y un diseño responsivo.

## ✨ Key Achievements
- **Jerarquía Visual**: Rediseño integral enfocado en la claridad tipográfica y la organización de contenidos complejos.
- **Layouts Avanzados**: Implementación de cuadrículas complejas con CSS Grid y Flexbox para una adaptabilidad total.
- **Accesibilidad**: Uso estricto de semántica HTML5 para garantizar una experiencia inclusiva para todos los usuarios.

## 🛠️ Technologies
- HTML5 (Semántica avanzada)
- CSS3 (Grid & Flexbox)
- Diseño Responsivo

## 📦 Features
- Interfaz optimizada para lectura de largo formato.
- Adaptabilidad total a dispositivos móviles.
- Estructura de navegación intuitiva y accesible.
